# Лицензии оформления

Иконки талантов в `icons/` взяты из набора [Game-icons.net](https://game-icons.net). Авторы: Lorc, Delapouite и другие участники набора. Лицензия [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). Цвет иконок изменён под деревья классов.

Шрифт Cormorant Garamond в `fonts/` распространяется по лицензии [SIL Open Font License 1.1](https://openfontlicense.org).

Пейзаж `images/backdrop.svg` нарисован для проекта.
